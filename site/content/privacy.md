## Hosting

The site is hosted on **GitHub Pages**, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA.

When you open a page on `drgtools.dev`, or fetch the install script (whether from this domain or from `raw.githubusercontent.com`), the request is served by GitHub's infrastructure. In serving it, GitHub records access data, which can include your IP address, the time of the request, the URL requested, your user agent and the referring page. GitHub processes this for delivery and for the security and integrity of its own service.

What GitHub collects, why, how long it keeps it, and on what basis it transfers data to the United States are set out in the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement). That statement is the authoritative description of GitHub's processing.

### Installing DRUDGE

Installing the tool involves a second request. The install script downloads the release archive for your platform from **GitHub Releases**, so your machine contacts GitHub's servers again and GitHub receives that request in the same way as any other. The same applies if you download a release asset by hand from the repository's releases page.

### What I can and cannot see

I do not operate a server for this site and have **no access to raw access logs**.

GitHub provides no visitor analytics for GitHub Pages sites. I have **no figures of any kind about visits to this website**. That means no page views, no visitor counts, no referrers, no countries and no device or browser data.

## Content loaded from other servers

The pages are static files. At the time of writing, every asset they load (styles, scripts, fonts and images) is served from this domain, and opening a page does not cause your browser to contact any other server. Links to GitHub and to external documentation appear in the text, and are followed only if you click them.

The site contains no analytics, no advertising, no tracking pixels, no social media widgets and no embedded third-party video.

If you find a request from this site to a server not described here, please tell me at the address above and I will either remove it or document it.

## Cookies and local storage

This site's own code sets **no cookies**.

The only item it stores on your device is your chosen colour theme (light, dark or system), kept in your browser's local storage so the site looks the same on your next visit. It is written only when you pick a theme, stays on your device, and is not transmitted. Documentation search runs in your browser. Search queries are not sent anywhere.

Because that storage provides a function you asked for, it does not require consent under Article 399 of the Polish Electronic Communications Law (Prawo komunikacji elektronicznej).

A hosting provider or CDN may set its own cookies for security purposes independently of this site's code. Where that happens it is governed by that provider's terms.
