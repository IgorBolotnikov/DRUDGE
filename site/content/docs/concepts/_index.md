DRUDGE has a few nouns, and each of them means exactly one thing. Read these pages to learn how they fit together. The [CLI reference]({{< relref "/docs/cli" >}}) and the [configuration reference]({{< relref "/docs/configuration" >}}) have the flags and keys.

- [Projects](projects/) link a local directory and its git repositories.
- [Tasks](tasks/) are the pieces of work, one markdown file each.
- [Drudgers](drudgers/) are the slots, sandboxes and workspaces the agents work in.
- [Sessions and runs](sessions/) are single runs of work on a Task and the files they leave behind.
- [Close-out](close-out/) is what happens to the branches and pull requests once a Session ends.
